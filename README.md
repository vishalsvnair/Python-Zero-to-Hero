# 150 Days of Python 

**From Python beginner to practical data analytics, automation, and
portfolio projects.**

Welcome! This repository documents a 150-day Python learning journey. It
is designed for beginners and gradually moves into intermediate Python,
data analysis, automation, APIs, databases, and applied projects.

## Learning goals

-   Build a strong foundation in Python programming.
-   Understand core data structures, functions, and object-oriented
    programming.
-   Analyze and visualize data using NumPy, Pandas, Matplotlib, and
    Seaborn.
-   Connect Python with SQL databases and REST APIs.
-   Automate practical business tasks and build portfolio projects.
-   Share daily progress and examples on LinkedIn.

## Suggested daily workflow

1.  Learn the day's concept.
2.  Write and run the code yourself.
3.  Test the code with a few different inputs.
4.  Add a short explanation and expected output to your notes.
5.  Share a concise LinkedIn post with one practical example.
6.  Commit your learning notes or code to this repository.

## Recommended tools and libraries

-   **Python:** Core programming language
-   **VS Code / Jupyter Notebook:** Development environments
-   **NumPy and Pandas:** Data manipulation and analysis
-   **Matplotlib and Seaborn:** Data visualization
-   **MySQL:** Database connectivity and SQL practice
-   **Requests and BeautifulSoup:** APIs and introductory web scraping
-   **OpenPyXL:** Excel automation
-   **Scikit-learn:** Introductory machine learning
-   **Streamlit:** Interactive data applications
-   **Git and GitHub:** Version control and project portfolio

## How to use this repository

1.  Clone or download the repository.
2.  Follow the day-by-day checklist in this README.
3.  Create a separate file or notebook for each topic.
4.  Tick a checklist item only after practicing the concept.
5.  Push your work regularly so your progress is visible.

``` bash
git clone <your-repository-url>
cd 150-days-of-python
```
